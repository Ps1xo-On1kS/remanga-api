# Неофициальный справочник ReManga API

## Статус документации

Это не официальная документация ReManga. Маршруты автоматически извлечены из production JavaScript, который загружает сам сайт. После обновления frontend их можно пересобрать командой из `README.md`.

Стандартная публичная Swagger/OpenAPI-схема не обнаружена. Поэтому справочник достоверно фиксирует HTTP-метод и URL, но не выдумывает отсутствующие в runtime-коде схемы тела и ответа.

Поле `bearer_capable` означает, что сгенерированный клиент умеет приложить Bearer-токен. Оно не гарантирует, что конкретный маршрут требует авторизации.

## Полезно для Minecraft

### Каталог карточек

```http
GET https://api.remanga.org/api/inventory/catalog/?count=100&page=1&rank=rank_s&ordering=-id
```

Ранги: `rank_a`, `rank_s`, `rank_re`, `rank_ev`.

### Публичный профиль

```http
GET https://api.remanga.org/api/v2/users/{user_id}/
```

Можно использовать для проверки одноразового кода в описании профиля при привязке Minecraft UUID к ReManga ID.

### Инвентарь карт пользователя

Сгруппированное представление:

```http
GET https://api.remanga.org/api/v3/inventory/items/cards/{user_id}/?count=100&page=1
```

Отдельные экземпляры карт:

```http
GET https://api.remanga.org/api/v2/inventory/items/cards/{user_id}/?count=100&page=1
```

В ответе доступны базовая карта, количество экземпляров, ID экземпляров, избранное, пробуждение, улучшение и часть игровых характеристик.

## Авторизация

Не просите игроков вводить пароль ReManga на Minecraft-сервере. В публичном клиенте есть обычный логин и социальные методы, но официальный OAuth-поток для стороннего Minecraft-сервера не обнаружен. Безопаснее подтверждать владение публичным профилем через временный одноразовый код.

Эти проекты полезны как примеры, но не являются подтверждением стабильности API и не заменяют разрешение ReManga.

## Ограничения и безопасность

- Не вызывайте изменяющие методы на реальных аккаунтах ради проверки.
- Не сохраняйте пароли, cookies или Bearer-токены игроков.
- Кэшируйте ответы и не опрашивайте API каждый игровой тик.
- Для публичного сервера согласуйте использование API и изображений с ReManga и правообладателями.
- Учитывайте `robots.txt`, условия сайта и возможные лимиты запросов.
