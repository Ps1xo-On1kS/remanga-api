# Сторонние компоненты генератора

Генератор использует следующие открытые компоненты:

- [Kotlin](https://github.com/JetBrains/kotlin) и стандартную библиотеку Kotlin, лицензия Apache 2.0;
- [kotlinx.serialization](https://github.com/Kotlin/kotlinx.serialization), лицензия Apache 2.0;
- Java Runtime из Eclipse Temurin, распространяемый в соответствии с GPLv2 with Classpath Exception.

Portable-архив создаётся стандартным инструментом `jpackage`. Встроенная Java-среда содержит собственный каталог `legal` с текстами лицензий модулей и сторонних компонентов.

Логотип и иконка ReManga получены из публичных ресурсов [remanga.org](https://remanga.org). Права на эти материалы принадлежат ReManga; они используются только для оформления связанного неофициального инструмента.

ReManga и связанные названия принадлежат их правообладателям. Генератор не является официальным продуктом ReManga.
