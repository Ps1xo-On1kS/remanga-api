# Уведомления в Discord

Автоматическое обновление может отправлять в Discord:

- номер новой frontend-сборки;
- общее количество обнаруженных API-методов;
- списки добавленных, изменённых и удалённых методов;
- ссылку на соответствующий GitHub Release.

Подробные обновления доступны на [Discord-сервере проекта](https://discord.gg/vF47ExMQpn). Для связи с автором используйте Telegram [@ps1xo_on1ks](https://t.me/ps1xo_on1ks).

Публичный репозиторий не содержит адрес канала, webhook-токен или другие данные доступа. Здесь опубликованы только документация, исходники для пользователей и открытые результаты сравнения версий.
